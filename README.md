# Sales Analysis Dashboard

## Project Overview

An interactive **Sales Analysis Dashboard** developed using **Microsoft Power BI** to analyze sales performance and generate actionable business insights. The dashboard provides a clear view of key performance indicators, sales trends, product performance, and category-level analysis.

## Objective

To analyze sales data, identify business trends, monitor key performance indicators, and support data-driven decision-making.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel
* Data Visualization

## Key Analysis

* Total Sales and Profit Analysis
* Sales Trend Analysis
* Product Performance Analysis
* Category and Sub-Category Analysis
* Order Analysis
* KPI Monitoring
* Interactive Filtering and Slicers
* 
## Key Skills Demonstrated

**Data Cleaning | Data Transformation | Data Analysis | DAX | Data Visualization | Dashboard Development | Business Intelligence | KPI Analysis**

## Project Outcome

The dashboard transforms raw sales data into an interactive and easy-to-understand visual report, helping users identify performance trends and make informed business decisions.
